# Brag Plan: Canto-0243

## What is this app?
Canto-0243 是一個粵語填詞查找工作台，用 0243/02493 數字碼、粵拼、押韻、聲母、近義和反義條件，在本機詞庫中快速搵可用詞條。

## The angle
把「填詞時一卡住就要翻詞典、查粵拼、搵押韻、再查近反義」拍成一個嚴肅但好快的產品 launch。重點不是抽象 AI，而是粵語創作者真正會用的查詢語法：`香港=`、`23就`、`~開心`、`~~`。

## Hook (first 2-3 seconds)
第一句直接問：「填詞卡住？」然後一條 0243 數字碼像搜索指令一樣打入畫面。觀眾即刻知道這不是普通字典，是為創作節奏而生的工具。

## Key moments (the middle)
- 搜尋框輸入 `香港=`，下方即時顯示「整詞同韻」查詢解釋。
- 結果卡一排展開：字詞、粵拼、0243 code 同時可讀。
- 模式籤逐個落位：0243、02493、粵拼、近反義。
- 資料庫數字鎖定：125,262 詞條，離線可用。

## Outro / punchline
收在「Canto-0243」和「粵語填詞，唔使慢慢撞字。」像一個真的創作工具廣告，但保留廣東話的直覺。

## User flow worth showing
開 PWA -> 輸入 `香港=` 或 `~開心` -> 讀查詢解釋 -> 結果卡出現 -> 切換模式繼續搵押韻/近反義。

## Tone
- Preset: polished
- Creative direction: 繁中粵語創作工具 launch film，暖色、利落、帶少少詩性
- Interpretation: 節奏要快但不吵，字要清楚，UI 模擬要比純文字更重要；幽默來自「填詞工具都可以拍到像正經產品發佈」。

## Storyboard

### Scene 1: Hook, 3s
Warm canvas. Giant text:「填詞卡住？」A mono query rail types `23 / 香港= / ~開心`. The ink accent flashes like a stamped mark.
Sequential/interaction: yes, query tokens type in one by one.
Audio intent: first soft impact, then quiet key/click ticks.
Audio-coupled idea: type the query tokens.
Music: warm upbeat bed.
Transition mood: soft but direct into Scene 2.

### Scene 2: Search Doing The Work, 4s
Recreated PWA search panel. Header reads ONE-RUN-RHYME. Cursor enters `香港=`. Below it appears:「查詢解釋：整詞同韻」and the primary button locks.
Sequential/interaction: yes, cursor focus, query typed, explain pill appears.
Audio intent: precise UI clicks.
Audio-coupled idea: simulated typing and submit tap.
Transition mood: clean slide into Scene 3.

### Scene 3: Results, 4s
Result cards fan in with words, jyutping, and code:「香江 hoeng1 gong1 0343」、「江港 gong1 gong2 3343」、「聲韻 sing1 wan6 2306」. Side metric:「125,262 詞條」「離線可查」.
Sequential/interaction: yes, 3 cards arrive one by one and hold.
Audio intent: soft card placements, one stronger hit on the metric.
Audio-coupled idea: card-by-card sequence aligned to beat grid.
Transition mood: hard editorial cut into Scene 4.

### Scene 4: Syntax Surface, 5s
Mode chips and syntax examples build a compact command board:「0243」「02493」「粵拼」「押韻」「近反義」then examples `23就`, `?+hon`, `~開心`, `~~`, `!!`.
Sequential/interaction: yes, chips and examples appear in rows.
Audio intent: restrained rhythmic ticks.
Audio-coupled idea: beat-aligned chip reveal, then hold for readability.
Transition mood: slow confident wipe into Scene 5.

### Scene 5: Outro, 5s
Brand lockup:「Canto-0243」with the line「粵語填詞，唔使慢慢撞字。」Final small copy:「PWA / portable / offline」。The ink mark settles and the music fades.
Sequential/interaction: none beyond final lockup.
Audio intent: final bell, music duck/fade.
Audio-coupled idea: logo lands near final strong cue.
Music: warm bed fading down.
Transition mood: final hold.
