# 詞語常用度與冷僻補詞退回：2026-11-06

維護者要求：詞語本身的日常常用度必須獨立於讀音常用度；新增詞不能因讀音是預設而佔據結果前列。沒有可靠詞頻的詞語由 AI 按實際用法判斷，過於冷僻的新增詞移出可用詞庫。

## 排序及資料

- 保留 Rime Essay 的原詞頻，新增固定版本 TUBELEX 中文影片字幕的實際出現次數及頻道分布，作日常接觸程度的補充；不使用 Jieba 收詞權重冒充詞頻。
- 詞語分級為 `0 日常高頻／1 通用書面與填詞／2 較少用或專門／3 冷僻退回`。語料未命中不代表冷僻，未命中項須另審，不能自動刪除。
- 已有語料的初始分級：頻道分布至少 20 或 Essay 至少 1,000 為 0；頻道分布至少 5 或 Essay 至少 500 為 1；其餘有來源記錄為 2。這些是可覆核的分級門檻，不是語言學真值。AI 可以按香港日常用法、常見書面／填詞用法覆核，原觀測值保留。
- 所有自建字面須有一筆明確分級及依據。AI 記錄與觀測詞頻分欄，不捏造出現次數。繁簡／香港字形按既有整詞正規化；合併來源字形的次數可相加，頻道分布只取最大值作保守下界，不聲稱取得去重後的聯集數。
- 共用搜尋順序改為 `漢字層 → 詞語分級 → Essay 詞頻 → 字幕頻道分布 → curated 常用集合 → 讀音等級 → 字面／粵拼`。同音異讀按相同詞語次序，同字面內仍以粵拼序；等號參考讀音仍先按讀音等級。缺字吻合、正韻命中等既有更外層優先條件保留。
- Python 及 PWA 使用同一份資料；在候選池排序完成後才分頁，驗證前 200 個字面和分頁續載，不只驗證傳入排序函數的幾筆示例。

這是維護者明示要求的排序契約調整，更新 CONTEXT 及 ADR-0007 的補充決策，不將新詞一律加入 `curated_common.txt`。

## 冷僻退回

只有逐項記錄為 3 的自建詞可退回，未知或單一來源未收錄不能作刪詞理由。常見成語、自然填詞短語及粵語口語保留；難以辨識的古典殘語、極窄術語與罕用變語優先覆查。

保留歷史詞源及原讀音審核表，另以明確退回記錄控制自建來源的有效收錄。退回不是讀音錯誤，不改單字讀音分級，亦不因本次退回而全域封禁其他詞源。來源快取須納入常用度／退回資料指紋，避免舊快取把退回詞重新帶入。

## 驗證與交付

以「事發經過、離開故鄉、迎風起」等無完整詞頻而自然的短語對照冷僻成語及專門術語；涵蓋常用詞排前、退回詞不從自建來源入庫、原有異讀與病 beng6 修正保留、快取失效、Python／PWA 一致、排序後分頁及前 200 個字面品質抽查。

完整來源重建在隔離副本進行；使用中詞庫及其他使用者改動保留。完成相關測試後提交並推送 dev；合併 main 或正式發佈依專案工作流程另行處理。

實際結果抽查後調整：同級保留 Essay 在字幕頻道分布之前，避免國語字幕覆蓋偏差壓過香港日常口語。日常級觀測門檻調至頻道至少 20 或 Essay 至少 1,000，使「科學家」「大學生」「自信心」等熟悉字詞優先於低頻稱謂；較偶爾使用的職業、費用及器材名稱另降至通用級。
