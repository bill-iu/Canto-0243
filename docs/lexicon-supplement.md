# 自建補充詞條

首輪範圍由維護者於 2026-10-19 選定：**通用中文＋填詞常用短語，兼顧粵語口語**。
先處理三至六字表達；長度係候選搜尋範圍，唔係正式詞庫嘅硬上限。

## 收錄方式

正式資料沿用 `data/lexicon/curated_lexicon.json`，由既有 `curated` 來源參與
詞條從源重建。唔另建 runtime 詞庫、唔改來源優先序，亦唔用 Essay 詞頻直接注入。
Desktop／PWA 繼續消費同一份建置後詞條庫。

補詞列嘅 `category`（`general`／`lyric`／`spoken`）與 `evidence` 只係審核資料，
唔係產品詞性分類，唔影響排序。`evidence=essay:原字面` 可追溯至
`data/essay/essay-cantonese.txt`；`user:2026-10-19` 係維護者提供嘅「迎風起」。
本批用 AI 輔助逐項檢視字面、語義與整詞讀音，唔代表經過人類逐條審核。

首批共 76 個表達：通用中文 34、填詞短語 31、粵語口語 11。
其中 75 個保留 Essay 字面證據，另 1 個係維護者提供嘅「迎風起」。
例：「向前走」「夜未央」「重新開始」「資料夾」「應用程序」「好多嘢」「傾下計」。
詞頻只用嚟發現候選；上述分類亦唔代表互斥嘅語言學類別。

第二批（`batch=2026-10-19-b02`）再收 261 個有 Essay 字面證據嘅表達：
通用中文 156、填詞短語 74、粵語口語 31。兩批合共 **337 個補充表達**。
例：「看不懂」「準備好」「手牽手」「一場夢」「不會忘記」「我冇事」「買嘢食」。
候選逐項校對語境讀音，包括數字 `sou3 zi6`、因為 `jan1 wai6`、社會 `se5 wui2`、
行為 `hang4 wai4`、成班人 `seng4 baan1 jan4`，唔採用逐字預設讀音作最後結果。

另有 6 個 `batch=2026-10-19-reading-repair` 列服務原有詞條修復／保存，唔計入新增缺詞數：

移入可重建詞源並使用五聲碼 `5`，避免重建遺失。原有 curated 嘅 9 個錯碼亦已對齊粵拼。

## 持續找缺詞

```bash
python scripts/propose_lexicon_supplement.py --output .tmp/lexicon-supplement.tsv
```

工具只讀指定詞條庫，並排除已加入 curated、但尚未重建到本機庫嘅字面。
候選經既有香港字形正規化後比對；同字形變體只保留最高一筆原始詞頻，唔相加。
預設列最多 500 個三至六字、詞頻至少 10 嘅全漢字缺漏，按詞頻降序、字面升序排列。
可用 `--min-length 2`、`--max-length`、`--min-frequency`、`--limit` 調整範圍，
或用 `--db`、`--essay`、`--curated` 指定輸入。輸出檔必須未存在，避免覆蓋審核工作。

每列一律係 `pending`，標音留空；工具唔猜讀音，亦唔自動寫入正式清單。
報表包括人名、店名、切句殘片等待剔除項；高詞頻唔等於可收錄。
補詞前須檢視：

1. 字面係自然、完整、對查找有用嘅中文／粵語表達；唔收偶然黏連或半句殘片。
2. 語料證據支持其用法；低頻但有填詞價值嘅完整短語可個別審定，唔設收錄詞頻硬閘。
3. 粵音按整體語義校對，尤其多音字、變調與語氣用法；唔直接把逐字預設拼接當詞級標音。
4. 正式列保留證據，使用規範六聲碼，唔覆寫既有高權威來源。

有更多已授權嘅語料或審定資料後再擴充來源；第一期毋須微調模型或新增 runtime 依賴。

## 掃描現有讀音

```bash
python scripts/audit_lexicon_readings.py --output-dir .tmp/lexicon-reading-audit
```

工具以唯讀方式掃描整個指定詞條庫，輸出帶輸入 SHA-256 嘅 `summary.json` 及
`findings.tsv`；輸出目錄必須未存在。全漢字列檢查粵拼導出六聲碼、音節數，以及
詞中讀音有冇列於 rime 單字參考表。英數混合字面有刻意嘅碼格式，唔用全漢字規則誤判。

**單字表未列 ≠ 錯讀。**「爸爸」`baa4 baa1`、「條件」`tiu4 gin2` 等正常詞級變調
會被標成待審，唔自動刪除。工具亦唔用字面詞頻判定讀音正誤；所有標記保持 `pending`。
確認錯誤後，把精確 `(字面, 舊粵拼)` 寫入 [詞庫勘誤](lexicon-corrections.md)，
每次來源合併後由 overlay 剔除；原字面嘅正確讀音保留。

第二批全庫掃描：本機 181,221 列中，11 列全漢字聲調碼與粵拼不符、36 列音節數待審、
7,746 列詞中讀音未見於單字表，共 7,793 列待審（含正常變調，唔係錯誤總數）。
本批確認剔除 **16 條錯讀**；完整精確目標及理由留喺 `lexicon_corrections.tsv`，
其餘待審資料繼續保留，唔宣稱全庫讀音已逐條審定。

兩個回歸例：

| 字面 | 剔除讀音 | 保留讀音／六聲碼 | 修正後 |
|------|----------|-----------------|--------|
| 善良 | `sin5 loeng4` | `sin6 loeng4`／`20` | 三檔 `40` 都唔命中 |
| 圖書館 | `tou5 syu1 gun2` | `tou4 syu1 gun2`／`039` | 三檔 `439` 都唔命中 |

核對來源：[CantoDict 善良](https://www.cantonese.sheik.co.uk/dictionary/words/4464/)、
[粵典 圖書館](https://cantowords.com/dictionary/%E5%9C%96%E6%9B%B8%E9%A4%A8)。
錯誤候選來自低來源異讀合併，唔係要改鬆檔碼等價規則；其餘正常異讀保留。

## 驗收與建置

```bash
python -m unittest tests.smoke.test_lexicon_supplement_proposals -q
```

驗收包含候選去重、輸入與輸出保護，以及從正式來源匯入隔離測試庫後搜尋
「迎風起」：`033起` 喺 m1 命中，m2／m3 唔命中；`039起` 三檔均命中。
另檢查全批格式、六聲碼與來源證據。現行正常建置會自動收錄補詞。

實際更新仍跟 [詞條庫建置／發佈流程](release.md)：完整保留關係補錄，
從源重建、過詞庫發佈閘及雙端驗收後先掛載。唔直接 patch 現行詞條庫，
唔用只重建 words 嘅空關係庫取代使用中資料；本批開發驗證用隔離測試庫。
