## Canto-0243 v1.1.0

**穩定版** — 合併 `dev`：Desktop + PyApp 交付（取代舊 Portable 路徑）、句格工作台狀態與查詢引擎分層加深、同聲母 `^` 語法，以及 About／殼圖示與詞庫快照刷新。

詞庫快照約 **171,082** 詞條列（`lyrics.db` · `words` 表）。Windows 套件改為 **Desktop** `Canto-0243.exe`（PyApp）；首次啟動需網路下載 CPython 3.11，其後可離線。

### 重點變更

- **Desktop 交付**（ADR-0068）：Windows 以 PyApp + 殼 `Canto-0243.exe` 出貨（唔再靠 `START.bat`／舊 portable zip 名）；安裝／首次就緒有 wry 進度殼；`runtime/` 與 **payload root** 解析 `lyrics.db`／側車資料
- **殼圖示與 About**：Desktop／PWA 用同一套 app 圖示；About 文案跟最新詞庫規模與來源說明
- **句格工作台加深**：`WorkbenchSession` 作狀態根；candidate-session 管 POS 分頁與 `engineTotal`；plan→MatchSpec 模組對齊並鎖 L1–L3 雙引擎 parity；退役 relation-pool shim；正式／legacy seam 可分（`CANTO_SEAMS_LEGACY`）
- **句格體驗**：清空整幅句格／句稿、雙擊或段手打改句面、通配符格與韻／聲參考、候選頁 400＋載入更多、唔再自動以 seed POS 濾候選、窄屏「建立句格」同行、PWA 搜尋／工作台 SPA 路由
- **詞性展示**：創作者篩選／顯示用 `pos∪show`；比較與詳情 chip 修正（例如「貪婪」標形容詞）
- **查詢語法**（ADR-0062）：`^` 表同聲母（與 `=` 同韻並列）；`?anchor` 與 `?+anchor` 雙引擎一致
- **工程／發佈**：行尾 LF（ADR-0063）；CI smoke 跟架構縫對齊；**v1.1.0 一次性 RC 路徑退役**，其後一律正常全量發佈＋ Pages workflow
