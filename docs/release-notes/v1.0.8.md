### 重點變更

- **分類詞語來源**（ADR-0057）：預設改讀 rime-cantonese-upstream 分類 CSV，排除 proper nouns；legacy `rime_phrase` 預設停用
- **短語收錄門檻**：擴充拒收後綴表 + 新增拒收字面表（維護者路徑）
- **詞條詳情**：音素欄位緊湊編碼解碼，聲母／韻母唔再誤顯示「—」
- **發佈策略**（ADR-0044）：退役獨立詞庫發佈；換庫＝新 semver 全量；程式刷新重用 Release 上 `lyrics.db`
- **PWA／窄屏**：閘前進度單調、搜尋教學速覽、頂區／結果 chip 密度與填滿排版
- **Smoke**：近反義池 facade 唔再洩漏 builder；registry 補 `PING_ZE_SERIAL`
