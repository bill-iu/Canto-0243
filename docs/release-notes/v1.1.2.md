## Canto-0243 v1.1.2

擴充通用中文、填詞短語及粵語口語，並移除已審核的錯誤讀音。PWA、Windows 及 macOS Desktop 使用同一份重建詞庫。

### 重點變更

- 三批補充詞庫合共新增 **536 個表達**（76 + 261 + 199），包括「迎風起」「花開花落」「只差一點」「講清楚」。今批優先檢視 Jason Y H Lee 的 105 首廣東歌語料，168 個補詞有跨曲證據，另有 31 個 Essay 口語補詞；保留來源署名及 CC BY 4.0 聲明。
- 移除 **27 筆錯誤讀音**（今批 11 筆），補回 7 筆既有字詞的正確讀音或編碼，並修正 9 筆原有補充詞條的編碼。
- 「善良」保留 `sin6 loeng4`（`20`），不再出現在 `40`；「圖書館」保留 `tou4 syu1 gun2`（`039`），不再出現在 `439`。
- 今批修正「未曾」「挽手」「見怪」「一覽」「一霎」「從頭開始」「志願」「愛錫」「折衷」「百家姓」的指定錯讀；有字典依據的變讀繼續保留。
- 全量重建詞庫共 **181,735 列、166,594 個字面**；同一 v1.1.2 覆蓋更新詞庫及兩平台完整桌面套件。
- 按字面遷移既有語意鄰居索引，配合新詞庫的詞條編號，保留原有關聯及分數；新增表達可查詞及聲調搜尋，本輪沒有重新訓練語意模型。
- 修正同版本、同檔案大小的 PWA 詞庫更新：本地檔案及下載快取以詞庫 SHA-256 分隔，既有 v1.1.2 用戶重新開啟後可取得本批資料。
- PWA 寬版詞庫資料列跟隨內容捲動。
- macOS 自動發佈改用現行 Desktop `.app` 打包流程。
- 修正桌面版啟動時依賴未附帶建庫工具的問題，已封存詞庫可直接通過啟動檢查。

「迎風起」的讀音為 `jing4 fung1 hei2`，編碼 `039`；`033起` 會按現行寬鬆比對模式匹配。
