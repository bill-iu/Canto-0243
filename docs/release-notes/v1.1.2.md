## Canto-0243 v1.1.2

擴充通用中文、填詞短語及粵語口語，並移除已審核的錯誤讀音。PWA、Windows 及 macOS Desktop 使用同一份重建詞庫。

### 重點變更

- 兩批補充詞庫合共新增 **337 個表達**（首批 76、第二批 261），包括「迎風起」等填詞短語。
- 移除 **16 筆錯誤讀音**，補回 6 筆既有字詞的正確讀音或編碼，並修正 9 筆原有補充詞條的編碼。
- 「善良」保留 `sin6 loeng4`（`20`），不再出現在 `40`；「圖書館」保留 `tou4 syu1 gun2`（`039`），不再出現在 `439`。
- 按字面遷移既有語意鄰居索引，配合新詞庫的詞條編號，保留原有關聯及分數。
- PWA 寬版詞庫資料列跟隨內容捲動。
- macOS 自動發佈改用現行 Desktop `.app` 打包流程。

「迎風起」的讀音為 `jing4 fung1 hei2`，編碼 `039`；`033起` 會按現行寬鬆比對模式匹配。
