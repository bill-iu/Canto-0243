## Canto-0243 v1.1.1

**穩定版** — 合併 `dev`：新增 **韻母比對檔**（正韻／通韻／腹韻／尾韻）、搜尋教學拆成 **搜尋指南** 與 **押韻指南**，以及教學／速覽 UI 微調。

詞庫快照沿用既有 `lyrics.db`／`words-lexicon.json`（程式與查詢行為更新；本版無大規模庫重建要求）。Windows 套件仍為 **Desktop** `Canto-0243.exe`（PyApp）；首次啟動需網路下載 CPython 3.11，其後可離線。

### 重點變更

- **韻母比對檔**（ADR-0078／0079）：搜尋與句格可選 **正韻**／**通韻**／**腹韻**／**尾韻**；通韻跟韻部分組與 **舒入相配**；整詞放寬同韻用 runtime 多鍵 union／intersect，唔撐大 `lyrics.db`
- **搜尋教學拆頁**（ADR-0080）：教學殼內 **搜尋指南**（語法）與 **押韻指南**（四檔說明＋同源韻母表渲染）；URL `guide=rhyme` 可深鏈
- **押韻指南 UI**：正韻／通韻格網與 chip 對齊；通韻卡名用「部／韻」；教學示例改為 **字面掣 + 說明**（完整教學）；空搜尋 **教你點用** 速覽仍為整卡可點
- **文案**：拿掉「同源表」／「分組一覽」等維護向提示，減少創作者噪音
