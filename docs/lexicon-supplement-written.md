## 粵拼、編碼與字形

上游只提供詞形，沒有可採用的粵音。初稿可參考既有詞級讀音及單字表，
但所有正式列均另作 AI 輔助整詞覆核；不把初稿自動升格為正式詞源。
再按多音字及既有詞級片段作第二輪檢查。這不等於經過人類逐條審核。

| 表達 | 收錄粵拼 | 正式六聲碼 |
|------|----------|------------|
| 這種 | `ze5 zung2` | `59` |
| 不復存在 | `bat1 fuk6 cyun4 zoi6` | `3202` |
| 冠狀動脈 | `gun1 zong6 dung6 mak6` | `3222` |
| 從容應對 | `sung1 jung4 jing3 deoi3` | `3044` |
| 利潤率 | `lei6 jeon6 leot6` | `222` |
| 行長 | `hong4 zoeng2` | `09` |
| 年老多病 | `nin4 lou5 do1 beng6` | `0532` |

使用既有 `get_0243_code()`，正式六聲映射為 `1→3、2→9、3→4、4→0、5→5、6→2`；
沒有另寫一套舊四類碼。含「病」字仍遵守維護者指定的 `beng6` 選擇。
詞級覆核例：[從容](https://cantonese.sheik.co.uk/dictionary/words/7702/)、
[裨益](https://words.hk/zidin/裨益)、[百分之的分](https://cantonese.sheik.co.uk/dictionary/characters/之/?cf=1&full=true)。
其餘抽查連結留於 metadata；不整批複製外部詞典標音。

來源「羣／群、藴／蘊、户／戶」等變體另核標準字面，正式列與實際 ingest 字面都記入審核表。
