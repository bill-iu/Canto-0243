# ADR-0078: 韻母比對檔（押韻模式）正交於搜尋 mode

領域詞彙：見 [CONTEXT.md](../../CONTEXT.md) § **同韻**、**韻母比對檔**、**正韻**／**通韻**／**腹韻**／**尾韻**、**韻母分組表**、**韻母比對檔排序**。  
相關：[0031](./0031-394052-canonical-code-and-search-modes.md)（聲調三檔）、[0062](./0062-rhyme-equals-initial-caret.md)（`=`／`^`）、[0072](./0072-workbench-candidate-snapshot.md)（候選快照身份）。Grill 共識（2026-07-29）。

## 問題

填詞常要「鬆一檔」押韻（傳統通韻、只押腹、只押尾），但本工具 **同韻** 歷來只有整段韻母精準。若開四個頂層搜尋 mode，會同 0243／近反義／平仄搶 enum，亦難同聲調精度組合。需要可選放寬，又唔改預設召回。

## 決定

1. **正交維度**：閉集 **韻母比對檔** = **正韻**｜**通韻**｜**腹韻**｜**尾韻**。只影響 **同韻**／final 錨命中；**唔**另開頂層搜尋 mode／URL `mode=`。與聲調精度、碼約束、同聲 AND。
2. **預設正韻**：等價歷來整段韻母一致；舊查詢／教學零驚喜。
3. **覆蓋**：搜尋列 final／`=`／串列韻錨、句格同韻、粵拼韻字母錨；複合末字韻若走 final 則跟。同聲／純碼／無韻錨不跟。
4. **韻母分組表**：git 靜態表 SSOT（v1 跟參考通韻圖凍結）。**通韻**為搜尋便利將入聲（`-p/-t/-k`）按共母音歸組（傳統戲曲多只論平，教學可註）。表外韻母回退該音節正韻，唔丟錨、唔即興 cluster。
5. **狀態（P1）**：每查詢分頁 session 內搜尋殼與句格共用；新 tab／硬刷新回正韻；**唔**寫分享 URL；第一期唔 localStorage 永久記。
6. **排序（R2＋M1）**：非正韻檔下兩層硬鍵——**正韻命中**（詞內每一同韻位皆全韻母一致）先於僅靠放寬入圍者；層內既有排序。唔做多級瀑布、唔按位計分。
7. **控件**：常駐可改（如 0243 三檔）；無韻錨時改檔唔改當前結果，只預選。UI 展示名 **押韻模式**；領域／IR 正名仍 **韻母比對檔**。
8. **位罝（產品）**：句格「本次替換條件」第一行 `聲調精度 | 押韻模式 | 原意關係 | 0243 碼`（select）。搜尋殼 meta：**兩組**分段 pill（聲調組｜押韻四檔組），全文 label；窄屏整組換行、唔改短字、唔降級 select。摺疊條件標題**唔**副標當前檔（H3）。
9. **解釋（E1）**：有同韻先標檔名；正韻空結果可 hint 放寬；已放寬仍空唔循環推更鬆。
10. **快照**：候選快照身份含韻母比對檔。雙端 Portable／PWA parity。

## 考慮過

| 方案 | 結論 |
|------|------|
| 四檔當頂層搜尋 mode | 同聲調家族打架、組合爆炸；拒絕 |
| 預設通韻 | breaking；拒絕 |
| 通韻嚴格唔入入聲 | 搜尋不便；v1 選搜尋用歸組 |
| 放寬池無正韻優先 | 鬆命中淹没精準；拒絕（選 R2） |
| 檔寫入 URL | 分享結果因人而異；拒絕 |
| 無韻時 disabled | 要先 `=` 先改到檔；拒絕 |
| 搜尋／句格各存各檔 | 行為分叉；拒絕 |
