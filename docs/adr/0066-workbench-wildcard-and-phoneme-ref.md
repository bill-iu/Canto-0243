# ADR-0066: Workbench wildcard slots + phoneme ref strings

通配起句／手改需要句面 `?`；通配格無字面時，條件列勾選同韻／同聲無法從句格取錨。Grill 共識：通配符格可鎖且與碼正交；同韻／同聲各加可選**參考字串**作額外維度。

## Decision

1. **通配符格**：起句／單格／段手打收 `?`／`_`／`%`（畫布統一 `?`）；可鎖；字面不限；可同時帶碼（同音／指定碼）。
2. **韻／聲參考字串**（各一欄）：空白＝跟句格（placeholder「跟原韻／跟原聲」）。非空時長度須＝該維度**已勾位置數**（整段＝段寬）；非法則忽略該欄（當空白）並提示。串內 `?`＝該已勾位退回句格。
3. **覆蓋**：參考位有漢字時**覆蓋**句格字面；外字 resolve 後多讀用第一個。
4. **可查**：僅有音位錨、無漢字種子亦可出候選。

## Considered

| Option | Result |
|--------|--------|
| 參考串永遠＝段寬並右補 `?` | Rejected — 長度跟勾選數（只勾第 2 字則合法長度 1） |
| 有字面時字面永遠優先 | Rejected — 選覆蓋以便外借錨 |
| 通配與碼互斥 | Rejected — 對齊搜尋字面通配＋碼約束 |

## Consequences

- `parseLineInput`／手改收通配；`buildPhonemeAnchors` 吃參考串。
- CONTEXT：**通配符格**、**韻／聲參考字串**；修起句／鎖定／手改 Avoid。
