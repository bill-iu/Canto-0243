# ADR-0052: 位置錨語法（通配碼錨、slot 連接符、串列／前綴等號）

領域詞彙：見 [CONTEXT.md](../../CONTEXT.md) § 通配碼錨查詢、slot 連接符、串列韻／聲錨查詢、前綴通配等號查詢、位置錨定。

整合並取代：[0012](./0012-wildcard-code-anchor-query-syntax-v2.md)、[0013](./0013-plus-slot-connector-alias-normalize.md)、[0014](./0014-serial-phoneme-anchor-and-prefix-wildcard-equals.md)。  
粵拼錨／歧義 m·ng 見 [0051](./0051-jyutping-and-anchor-phoneme.md)；碼夾等號見 [0028](./0028-code-sandwich-equals-unification-and-per-digit-loose-variants.md)；分派 seam 見 [0046](./0046-query-dispatch-seams-and-ssot.md)。

## 1. 通配碼錨與音節槽（原 0012）

1. **硬切換** — `?30人` 等唔再當「逐字元四格」mask；詞長 = 1 + 碼位數，碼約第 2…N 音節，尾參考字同韻。
2. **Normalize** — 首格字面 `X…` ≡ `+X…`；通配左中格 `?{字}…` → 插 slot 連接（見 §2）；**唔**對 `?30人`、純碼尾 `23?` 亂插。
3. **單字韻錨** `?{字}=`（無連接符）→ 詞長 1；`?+{字}=` 二字；廢止舊「`?就=`＝二字」語意。
4. **中格韻** `?{碼}{字}=?` 須 `=`；無 `=` 的 `?{碼}{字}?` → 空結果 + hint。
5. **純碼＋通配**（`23?`）維持逐位缺字。

## 2. slot 連接符別名（原 0013；canonical 以 CONTEXT 為準）

1. **規範形 `+`**；輸入別名：`*`、`＊`、`﹡`、全形 `＋` → normalize 為 `+`（歷史 0013 曾寫 canonical `*`，已廢，以 CONTEXT § slot 連接符為準）。
2. 右邊須緊接參考字或粵拼錨，**唔**可接 0243 碼；禁**相鄰**多個連接符（用 `?` 表通配槽）。
3. 非法 → 空結果 + 固定 hint（連續連接符／`+` 後接碼）。
4. **詞長分軌** — `23o`（二字末韻）≠ `23+o`（三字）；`23我=` ≠ `23+我=`。
5. 粵拼錨側：`?hon` 等可收斂為帶連接符規範形；`3?ngo4` 中間 `?` 可改寫為 `+`（見原 0013 10c）。

## 3. 串列韻／聲錨與前綴通配等號（原 0014）

1. **串列掃描** — 左至右：數字碼、`{碼}{字}=` 韻、`{碼}={字}` 聲；可含 `?` 通配單槽；**唔收** `*`／`_`／`%`／`@`（走其它分派）。
2. **分派** — `is_framed_equals`（含 `2=我3`）先於串列；串列要 **≥2 參考字**（單參考碼夾仍碼夾等號）。
3. **前綴通配等號** — `?{≥2 字}=`；漏尾 `=` → hint；`?2我=3` 唔收。
4. **Normalize** — `?{單字}=` → `{單字}=`。

**Consequences** — parse／normalize 邊界集中；指南與 `check_guide_examples` 跟規範形 `+`；與 0051 粵拼錨模板共存、分派優先序見 CONTEXT。
