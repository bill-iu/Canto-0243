# ADR-0061: 語彙族細分（成語／俗語／諺語／歇後語）與外源邊界

領域詞彙：見 [CONTEXT.md](../../CONTEXT.md) § 詞性與分類（**語彙族**、**語彙族篩選**、**詞性提案**、**詞性覆蓋母體**）。

## 決策

1. **語彙族** 閉集由單傘擴為：空（普通詞）｜`idiom`（**熟語** 傘）｜`chengyu`（**成語**）｜`suyu`（**俗語**）｜`yanyu`（**諺語**）｜`xiehouyu`（**歇後語**）。一字面仍**單值**；四葉**蘊涵**熟語（唔雙寫傘+葉）。
2. **標註優先序**：高信任結構化歇後語 `term`→歇後語（覆蓋同字面較泛舊 family，舊值留審核紀錄）→ 其餘先成語（中檔：定型＋典故／對仗／高度非組合義至少一項）→ 其餘口語→俗語（口語壓過「似諺語」句式）→ 其餘書面→諺語 → 分唔清留 `idiom`。
3. **遷移**：既有 `idiom` **保留**；有過審提案先改葉。細分 KPI 母體＝已標 `idiom` 之字面；終局＝四葉之一或顯式留 `idiom`；品質 **>90%**。唔要求全庫葉級。
4. **產品消費**：**詞條**面板展示葉名或傘名；搜尋結果與句格工作台提供 **三軸詞性篩選**。詞類／語彙族／語態各軸內多選 OR，非空軸之間 AND；葉篩精確，「熟語」＝全族，缺已啓用軸之高信任展示標籤唔入選。schema 一支援即出篩選。**同詞性**／工作台同桶仍**只睇詞類**。
5. **外部固定語來源**分兩級：無逐筆結構化類型嘅 membership（例：China-idiom）只可作離線 **詞性提案**；已有專案引用、授權清晰且由來源 registry／content type 明確標類嘅資料（例：Cantonese.md `idioms`＝**歇後語**）可作高信任審定源。後者只標 `term`；`answer` 可入詞庫但唔自動取得 family。未知 content type fail closed；禁止從 explanation 猜類、加入 runtime dependency、或當第二套詞庫權威。
6. **歇後語詞類**唔由 family 或後語單一核心語素自動推出。逐筆以 `answer` 整體句法功能為主證據，以釋義／例句驗證；容許多詞類，衝突或只可判完整小句則留 `u`。family 可高信任而詞類仍未定。
7. 本批遇到補缺字面時，逐字讀音可引用按 Unicode 版本固定嘅 **Unihan** 粵音欄位，但須保留碼位、版本及 property 級來源，並只作加法候選；Unihan 只豐富已由其他可信來源收錄／同批確定新增嘅字面，唔自行開新字入庫，亦唔自動覆蓋詞語級證據。`牛𡁻牡丹` 收 `ziu6`（Unihan `kCheungBauer`）與 `zeu6`（粵音資料集叢），排除 Cantonese.md 嘅 `zoek6`；來源衝突留稽核。
8. 保留來源原字並把有效漢字判定統一擴至完整 Unicode `Script=Han`（含 supplementary planes）；匯入、後端查詢、前端輸入須一致。唔將 `𡁻` 代換成 `嚼`，亦唔只為 U+2107B 開特例。
9. Cantonese.md 由維護者明示刷新至指定 upstream commit；manifest 固定 commit SHA、archive SHA-256、content-type mapping 同解析／分類統計。一般建庫只重放固定快照；刷新先產生新增／改類／刪除 diff 供審核，唔直接跟 `main`。Unihan 同樣固定 Unicode release version。

## 理由

P2 傘已標大批固定語，創作者需要成／俗／諺／歇後語可辨與可篩，但全量四選一成本高、邊界糊（尤其口語諺語）。單值＋葉蘊涵傘保留漸進遷移；歇後語引子角色比泛稱成語／熟語更具體，口語優先亦令粵語俗語唔被書面「諺語」吞併。外源 membership 召回高但未必逐筆標類，只適合提案；結構化 content type 則可提供可稽核高信任分類。兩者皆唔應變成 runtime dependency 或第二詞庫權威。

## 後果

- ingest／carrier／client 閉集與標籤表須認四葉碼；舊載體只有 `idiom` 時葉篩結果少、傘篩仍可用。
- 提案管線可選用外源 membership；CI／發佈產物**唔**依賴該套件。
- 俗／諺暫無對等外源，多靠人手／agent；可另 ADR 再引入。
- 與 ADR-0058（獨立詞性載體）、ADR-0060（fragment／alias）相容；唔改 lyrics.db 主表權威。
