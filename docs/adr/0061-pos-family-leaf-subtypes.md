# ADR-0061: 語彙族細分（成語／俗語／諺語）與外源提案邊界

領域詞彙：見 [CONTEXT.md](../../CONTEXT.md) § 詞性與分類（**語彙族**、**語彙族篩選**、**詞性提案**、**詞性覆蓋母體**）。

## 決策

1. **語彙族** 閉集由單傘擴為：空（普通詞）｜`idiom`（**熟語** 傘）｜`chengyu`（**成語**）｜`suyu`（**俗語**）｜`yanyu`（**諺語**）。一字面仍**單值**；三葉**蘊涵**熟語（唔雙寫傘+葉）。
2. **標註優先序**：先成語（中檔：定型＋典故／對仗／高度非組合義至少一項）→ 其餘口語→俗語（口語壓過「似諺語」句式）→ 其餘書面→諺語 → 分唔清留 `idiom`。
3. **遷移**：既有 `idiom` **保留**；有過審提案先改葉。細分 KPI 母體＝已標 `idiom` 之字面；終局＝三葉之一或顯式留 `idiom`；品質 **>90%**。唔要求全庫葉級。
4. **產品消費**：**詞條**面板展示葉名或傘名；搜尋結果與句格工作台提供 **三軸詞性篩選**。詞類／語彙族／語態各軸內多選 OR，非空軸之間 AND；葉篩精確，「熟語」＝全族，缺已啓用軸之高信任展示標籤唔入選。schema 一支援即出篩選。**同詞性**／工作台同桶仍**只睇詞類**。
5. **外部成語 membership**（例：China-idiom／其 CSV 字面集）**只**可作 **`chengyu` 詞性提案** 離線源：繁化後 ∩ 詞庫 → 提案 → **詞性提案審核** → SSOT。**禁止**加入產品 dependency、runtime import、vendoring 為查詢／接龍後端、或當第二套詞庫權威。

## 理由

P2 傘已標大批固定語，創作者需要成／俗／諺可辨與可篩，但全量三選一成本高、邊界糊（尤其口語諺語）。單值＋葉蘊涵傘保留漸進遷移；口語優先令粵語俗語唔被書面「諺語」吞併。外源成語表召回高、語體偏普通話書面，只適合提案種子；併入 dependency 會鎖死離線邊界並混淆權威。

## 後果

- ingest／carrier／client 閉集與標籤表須認三葉碼；舊載體只有 `idiom` 時葉篩結果少、傘篩仍可用。
- 提案管線可選用外源 membership；CI／發佈產物**唔**依賴該套件。
- 俗／諺暫無對等外源，多靠人手／agent；可另 ADR 再引入。
- 與 ADR-0058（獨立詞性載體）、ADR-0060（fragment／alias）相容；唔改 lyrics.db 主表權威。
