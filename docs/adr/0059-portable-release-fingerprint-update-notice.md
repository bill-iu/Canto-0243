# ADR-0059: 以套件發佈指紋做更新提示（唔自動覆蓋）

領域詞彙：見 [CONTEXT.md](../../CONTEXT.md) § **套件發佈指紋**、**套件更新提示**、**指紋略過**、**Desktop 套件**（舊 Portable）、**全量發佈**。

與 [ADR-0044](./0044-portable-delivery-and-release.md)／[ADR-0068](./0068-desktop-pyapp-delivery.md) 並讀：本決策補「創作者本機點知有正式新發佈」同「同 tag 換庫與套件一致性」。運送形態見 0068；**現行仍拒** launcher 自動覆蓋（0068 確認；全自動為長遠目標）。

## 決策

1. **身份** — 正式 **Desktop 套件** 以 **套件發佈指紋** 識別：`release tag` ＋ **本平台套件 digest** ＋ **`lyrics.db` sha256**；三者同一次發佈寫入套件。只比 semver／只比 **詞庫版本** 不足（同 tag 可換庫或重打包）。
2. **來源** — 對 GitHub 最新**非 prerelease** Release；遠端 beta／`prerelease` **唔**觸發穩定軌道。唔用 `git fetch` 當套件更新真相（套件唔係 clone）。
3. **時機** — 每次啟動前短超時核對；逾時／失敗 **fail-open**（當無更新）；**唔**阻 **就緒閘解鎖**。
4. **提示** — **套件更新提示**＝終端非阻塞摘要 ＋ 產品 UI 橫幅；v1 **唔**做系統 MessageBox。CTA：開正式 Release；附可複製下載指令；明確須關閉程式後人手解壓覆蓋成個 **Desktop 套件**。
5. **拒自動覆蓋** — **唔**原地一鍵熱更新執行環境／UI／庫（檔案鎖、半更新損壞、與 **免安裝交付** 摩擦大）。**唔**預設開 PyApp self-update。
6. **指紋略過** — 「稍後」綁某個**遠端**指紋；同一指紋唔再提，指紋一變再提。唔用固定 N 日、唔預設永久關檢查。
7. **舊套件** — 無本機指紋 ⇒ **唔**檢查、**唔**提示（唔降級猜 tag／只 hash 庫）。
8. **發佈約束** — **全量發佈** 下「同一 tag 換庫快照」**必須**同時重打並上傳對應 Desktop 套件，令 Release 庫資產、套件內庫與指紋一致；禁止只換庫資產而期望「下整包」仍正確。

## 理由

創作者要知「有新正式包」，但 Desktop 已解壓、可離線；自動覆蓋代價高、git 語意唔適用。指紋三件套同時覆蓋新 tag、程式-only 刷新、同 tag **詞庫刷新**；穩定軌道忽略 beta 避免誤擾。提示與發佈政策綁死，避免 Release 上庫新、套件內庫舊嘅誤導。

## 後果

- 發佈／打包須寫入並上傳與指紋一致嘅印章；`docs/release.md` 須反映「換庫必重打包」。
- 啟動鏈與 `/app/` 橫幅要共用同一「是否過期／略過」語意；無網唔應拖垮雙擊即用（**首次** PyApp bootstrap 可需網，見 0068）。
- 已流出無指紋舊包保持靜默，直至用家手動換到有指紋之正式包。
- 若日後要半自動下載到旁路目錄或整包自動同步（仍宜原子、可回滾），可另 ADR；唔默默升級成半套原地覆蓋。

## Considered Options（摘要）

- 只比 tag／只比 `lexiconVersion` — 拒（漏同版換庫／程式刷新）。
- 啟動硬閘擋至用家處理 — 拒（違免安裝即用）。
- 一鍵原地 update／PyApp self-update 作預設 — 拒（可靠性／鎖檔；0068 長遠可再議）。
- 無指紋舊包當過期每次提示 — 拒（騷擾；半套探測與「三件套一致」打架）。
