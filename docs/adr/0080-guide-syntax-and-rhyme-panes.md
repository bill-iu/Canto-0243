# ADR-0080: 搜尋教學殼拆「搜尋指南」與「押韻指南」

領域：見 [CONTEXT.md](../../CONTEXT.md) § **搜尋教學**、**搜尋指南**、**押韻指南**、**韻母分組表**。  
相關：[0078](./0078-rhyme-match-profile.md)。Grill 共識（2026-07-29）。

## 決定

1. 產品入口仍為單一 **搜尋教學**（`view=guide`）；頁內子頁 **搜尋指南**（原語法全文）與 **押韻指南**（四檔）。
2. 預設 **搜尋指南**；URL 可選 `guide=syntax`｜`guide=rhyme`（缺省＝syntax）。
3. 押韻指南四檔完整分組由 **韻母分組表** 同源資料渲染（`rhymeGroupsForProfile`），文案唔手抄第二份表。
4. 每檔可點小例開搜尋 tab；第一期唔納入全量 **搜尋教學驗收** 探針清單。
5. Desktop／PWA 同一契約；**搜尋教學速覽**唔拆兩頁。

## Status

`accepted`
