# ADR-0062: 同韻用 `=`、同聲用 `^`（可省略僅單錨碼夾）

領域詞彙：見 [CONTEXT.md](../../CONTEXT.md) § **等號（韻）**、**聲錨符**、**碼夾等號查詢**、**同韻**、**同聲**。  
相關：[0028](./0028-code-sandwich-equals-unification-and-per-digit-loose-variants.md)（碼夾 MatchSpec／鬆檔不變）、[0052](./0052-positional-anchor-query-syntax.md)（位置錨／串列／通配）。Grill 共識（2026-07）。

## 問題

左右跳嘅 **等號（韻／聲）**（`字=`＝韻、`=字`＝聲）精準但難記。CanTone 式 `>`／`<` 兩符且難打，唔採用。需要更短口訣，且**唔改召回**（同一 MatchSpec／結果）。

## 決定

1. **純字面**（`就`、`香港`）維持 **詞條 lookup**；查同韻須顯式尾 `=`（`香港=`）；查同聲用前綴 **聲錨符** `^`（`^香港`；多字＝逐字聲母）。
2. **同韻**規範：參考字**後** `=`。**唯一可省**：單錨碼夾 `{碼}{字}` → normalize 補尾 `=`（既有 ADR-0028；如 `23就`）。**串列唔省**（`04困=49倒=`，唔接受 `04困49倒` 當雙韻錨）。
3. **同聲**規範：參考字**前** `^`（`^就`、`?^就`、`2^我3`、`04^困49^倒`）。`^` 永遠貼參考字前。
4. **舊形相容**：`=就`、`?=就`、`2=我3`、`04=困49=倒` 等左 `=` 同聲形仍解析為同聲；normalize／**查詢語意解釋**偏向規範 `^`；**搜尋教學**只教新形。
5. **唔引入** `>`／`<`。MatchSpec、分派家族、碼鬆檔、尾韻 union／內嵌聲 pron_rank **行為不變**——只換表面標記與文案。
6. **實施前狀態**：本 ADR 鎖定產品語法；parser／指南改碼另開任務。雙標記（如 `^香=`）實施時拒絕或 hint，唔靜默揀邊。

## 考慮過

| 方案 | 結論 |
|------|------|
| 維持左右 `=` | 難記；拒絕 |
| CanTone `>`／`<` | 兩符＋難打；拒絕 |
| 純省略 `=` 當韻、另符表聲（本決定） | 口訣最短；`^` 查詢語法未佔用；接受 |
| 硬切舊 `=字` | 斷書籤；拒絕（選相容＋教學只教新形） |
| 串列韻亦可省標記 | 歧義（`04困49倒`）；拒絕 |

## 後果

- CONTEXT 拆 **等號（韻）**／**聲錨符**；碼夾示範規範形改 `2^我3`（舊形仍合法）。
- 實施須雙端（Portable＋PWA）parity：舊新表面形 → 同一 spec／結果；golden／guide／explain 跟規範形。
- ADR-0028 嘅「內嵌聲」語意保留；表面由 `{碼}={字}{碼}` 規範為 `{碼}^{字}{碼}`。
- ADR-0052 串列掃描表面由 `{碼}={字}` 規範為 `{碼}^{字}`（舊形相容）。

## Status

`implemented`（parser／normalize 雙端已認 `^`；舊左 `=` 相容；指南文案可另開）
