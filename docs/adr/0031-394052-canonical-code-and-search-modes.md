# 394052 碼為 canonical 與三檔搜尋模式

詞庫聲調碼由 **0243 碼**（三聲與五聲皆 `4`）改為 **394052 碼**（三聲 `4`、五聲 `5`）。頂欄 **0243搜尋模式** 增第三粒 **394052模式（矩陣，`m3`）**；**0243模式**／**02493模式** 共用聲調矩陣正規化，鬆檔差異保留（0243 全鬆、02493 僅 `4↔5`、394052 零鬆檔）。遷移採收錄管線一次重建並 bump 詞庫版本，唔雙讀舊存儲。

**考慮過：** 查詢層投影舊庫（詞庫不變）— 五聲仍存 `4`，矩陣只在比對時拆；拒絕，因創作者需用碼位 `5` 精確查五聲，且與 0243.hk 矩陣模式一致。**雙讀過渡** — 拒絕，分叉成本高。

**後果：** `TONE_MAP`／`get_0243_code` 路徑、golden queries、ranking 索引、兩端 `code-variants` 須同步；平仄串列改靜默轉 `m3`（`MATRIX_394052_MODE`）。實作分兩 PR：PR1 codec+ingest+manifest；PR2 UI `m3`+guide+轉接。

**領域詞彙：** [CONTEXT.md](../../CONTEXT.md) § **394052 碼**、**0243 碼（舊）**、**02493 碼**、三檔搜尋模式。
