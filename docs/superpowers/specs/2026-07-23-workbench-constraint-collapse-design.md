# 句格工作台替換條件面板摺疊設計

## 共識

- `ConstraintBar` 初次載入時為摺疊。
- 點擊標題列的展開／摺疊按鈕才顯示或收起條件內容。
- POS 篩選、復原按鈕和展開／摺疊入口屬於常駐操作列，收起時仍然可見。
- 摺疊狀態只存在目前頁面的元件狀態，不寫入 `localStorage`；重新載入或新工作台回到摺疊。
- 不加入高度動畫；狀態即時切換，保留現有表單值和候選查詢行為。

## 實作邊界

在 `ConstraintBar` 內新增 disclosure state 和可聚焦的標題按鈕，將現有下拉選單、音位 checklist、說明文字包在條件內容區。用 `aria-expanded` 和 `aria-controls` 表達狀態，並以 `hidden`／等效 CSS 隱藏內容；不改替換條件資料模型、回調或查詢計劃。

標題按鈕只負責切換面板內容；POS 篩選和復原繼續由現有操作列處理，避免操作按鈕與 disclosure 互相攔截。桌面和窄屏沿用同一狀態規則，現有窄屏欄位排列保留。

## 驗收

1. 首次進入工作台，條件內容不可見，POS 篩選和復原操作仍可見。
2. 鍵盤可聚焦標題按鈕，點擊或按 Enter／Space 可展開／摺疊；`aria-expanded` 與內容狀態同步。
3. 展開後現有條件控件可正常修改；摺疊／展開不清除任何已選值，也不新增查詢副作用。
4. `client` lint、build 通過；桌面與 375px 窄屏不出現水平溢出。

## 不做

不持久化摺疊偏好、不新增動畫、不修改工作台 POS 篩選外觀、不重做候選查詢或替換條件資料模型。
