# 句格工作台窄屏排版與觸碰分隔設計

## 共識

- 窄屏 `逐字句格` 標題與操作區不再互相擠壓；標題保持橫排，操作按鈕另行排列。
- 「最近一次操作可復原」移到句格標題區下方的獨立狀態行，避免與按鈕或標題重疊。
- 替換條件列的標題、POS 按鈕與短文案「復原」保持同一列；「復原」取代長文案「復原最近一次套用／放寬／手改」。
- 替換條件內容維持預設摺疊；窄屏採緊湊正常流，候選詞條由現有畫面流程自然推近，不新增 sticky 浮層或遮罩。
- 375px 窄屏仍維持每行 6 格；只增加格與格之間的安全空隙，讓相鄰字面較不易誤觸。
- 不修改雙擊判定時間；既有雙擊改字與跨格連續單擊語意保留。

## 實作邊界

在 `SentenceCanvas` 將復原提示從操作按鈕列移到獨立狀態行；在 `ConstraintBar` 縮短復原按鈕文案並維持標題／POS／復原同列。窄屏 CSS 只調整標題區排列、垂直留白與六格 grid 的欄間距，不改句格資料、鎖定事件或候選查詢流程。

## 驗收

1. 375px 視口下「逐字句格」與「點擊鎖定，雙擊改字」為正常橫排，不被右側操作按鈕壓成逐字直排。
2. 「最近一次操作可復原」不與任何文案或按鈕重疊；無復原狀態時不佔用不必要空間。
3. 替換條件列的標題、POS 與「復原」同列，條件內容仍可正常摺疊／展開。
4. 375px 下仍一行顯示 6 個字面格；格間可見安全空隙，鎖定、選讀音與鍵盤操作不變。
5. 鎖定後候選區在緊湊正常流中更接近首屏；頁面仍可完整垂直捲動。

## 不做

不改雙擊時間、不減少窄屏每行格數、不新增 sticky 候選浮層、不改候選排序／查詢、不把復原提示改成另一套 undo 資料模型。
