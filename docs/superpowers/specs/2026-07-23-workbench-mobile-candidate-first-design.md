# 句格工作台窄屏候選首屏與標題列補充設計

## 共識

- 以 375px PWA 窄屏為主要驗收尺寸；輸入列維持單行，縮小「建立句格」與「復原」按鈕，但保留可用觸控高度。
- 句格畫布的三個操作按鈕固定在「逐字句格」同列右上角；「點擊鎖定，雙擊改字」保持單行，不被按鈕擠壓或斷行。
- 當 `direct_syn` 與 `semantic_related` 都沒有結果，而 `sound_only` 有結果時，窄屏把 `sound_only` 視覺提前，讓鎖定字面後不用先捲動就能看到候選詞條。
- 只要 `direct_syn` 或 `semantic_related` 任一組有結果，就恢復 `sound_only` 排第三的原有順序。
- 沒有結果的「直接近義／語意相關」保留可見的群組標題與數量，預設收合；使用者點擊標題後才展開空結果提示。

## 邊界

- 候選群組的資料分組、詞條順序、載入更多及候選套用流程不變。
- 候選提前只套用於窄屏 CSS；桌面版維持原本群組順序。
- 不新增 sticky 候選浮層，也不改變頁面可捲動行為。

## 驗收

1. 375px 寬度下，輸入 placeholder 可完整顯示；「建立句格／復原」仍可操作。
2. 窄屏鎖定字面後，只有音格候選時，「只合音格」在前兩個空群組之前可見。
3. 前兩組任何一組有候選時，「只合音格」仍位於第三組。
4. 空的前兩組可逐組點擊展開與收合，且群組標題具備鍵盤焦點與展開狀態。
5. 畫布操作按鈕與「逐字句格」同列；操作提示維持單行。
