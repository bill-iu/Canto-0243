# v1.1.0-only Local RC Implementation Plan

**Goal:** Build, verify, and later publish the exact locally accepted `v1.1.0`
Windows/PWA artifacts without rebuilding during publish.

**Scope:** One-off `v1.1.0` only. No generic RC framework and no `/beta/` Pages.

## Task 1: Lock the one-off contract

- [x] Amend the approved spec to reject tags other than `v1.1.0`.
- [x] Confirm public TDD seams for manifest creation, verification, and no-build Pages deployment.
- [x] Add failing behavioral tests for the fixed version and immutable artifact set.

## Task 2: Candidate identity and integrity

- [x] Implement the minimal manifest create/verify CLI.
- [x] Bind source commit, DB fingerprint, artifact names, sizes, and SHA-256.
- [x] Reject dirty/mismatched source, missing/extra assets, and non-`v1.1.0` tags.

## Task 3: Local Windows/PWA candidate builder

- [x] Add the `v1.1.0`-only PowerShell orchestration entry point.
- [x] Reuse existing lexicon, PWA, and Windows portable builders.
- [x] Package the exact Pages directory and write the manifest last.

## Task 4: Publish without rebuild

- [x] Add a manifest-verified upload mode that never invokes build/export commands.
- [x] Change Pages workflow to download and deploy the stored Pages artifact.
- [x] Remove the tag-push upload race and retain explicit retry behavior.

## Task 5: Gates and documentation

- [x] Add workflow/release seam self-checks.
- [x] Update release and PWA maintainer docs for the one-off path.
- [x] Run focused RC/production-artifact checks and diff checks; skip the exhaustive suite per maintainer direction.

## Task 6: Integrate before building

- [ ] Commit and push implementation to `dev`.
- [ ] Create and merge the approved `dev -> main` PR.
- [ ] Confirm local `main == origin/main` and `origin/dev` is merged.

## Task 7: Build and hand off local RC

- [ ] Build the `v1.1.0` database and exact candidate artifacts on `main`.
- [ ] Run formal PWA and relocated Windows portable acceptance.
- [ ] Present manifest, hashes, paths, and test instructions for maintainer acceptance.
- [ ] Do not create the tag, release, or change Pages before explicit acceptance.
