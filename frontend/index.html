所有搜尋語法

每個例子都可以直接執行。點擊後會回到搜尋頁、套用建議模式，並送出查詢。口訣：= 在錨字後 → 韻母；在錨字前 → 聲母（一般查詢與 + 延伸段相同）。

基本說明

打數字，搵 394052 碼同音嘅詞條。每個數字對應一個音節嘅聲調（394052 碼），查詢有幾個數字就搵幾個音節嘅詞。例如打「23」，會搵整詞碼同「23」同音嘅二字詞，包括「自己」、「第一」、「做好」。打「232」會搵三字同音詞，例如「是不是」、「自己做」、「沒關係」。0243模式鬆檔；02493模式僅 4↔5 鬆檔；394052模式六聲碼逐位精確（三聲 4、五聲 5 唔互通）。平仄串列（如 PZ）會自動切換 394052模式。

打漢字，查詞條讀音同編碼。例如打「開心」、「明白」、「食飯」，會見到粵拼、394052 碼，以及同音候選。切換近反義模式，可以直接列出該詞嘅近義、反義同語意相關字。

打數字加錨字，逐格約束韻或聲。串列掃描：每位數字一音節碼，{碼}{字}= 韻錨、{碼}={字} 聲錨。例 23就=（二字尾格同「就」韻）、04困=49倒=（四字韻錨）。加槽用 +，如 23+就=（三字尾格同韻）；尾字字面固定用 23@手。

缺字同加長位置。通配用 ?／_／%；加槽用 +，例 +香??、23+就、?30+人。輸入 * 仍接受（等同 +）。

打幾個漢字加等號，搵「同韻」或「同聲」。打「開心=」會搵整詞逐音節同「開心」同韻嘅詞。打「=最好」會搵整詞逐音節同「最好」同聲嘅詞。單格聲母錨打「=我?」、「?=就」。碼夾等號如「2我=3」、「2=我3」，可同時約束 394052 碼同一格聲或韻。

打一個漢字加等號，搵「同韻」或「同聲」詞。打「就=?」會搵首字同「就」同韻嘅二字詞；打「就=」會搵同「就」同韻嘅單字。聲母錨打「=就?」、「?=你」。口訣：「=」在錨字後比韻母，在錨字前比聲母。

打粵拼，精準搵漢字。冇聲調如「syut」，搵粵拼相同嘅單字（忽略聲調）；有聲調「ming4 baak6」會搵準確讀音嘅字「明白」。近反義模式唔收粵拼，請改打漢字或切換 0243搜尋三檔之一。

打粵拼錨，唔使打漢字參考字。規範形如 ?+yut?、?+hon、3+ngo4、23o（二字韻母）／23+o（三字碼尾韻母）。?+m?、3m4 會分聲母／韻母兩列。

近義、反義同複合詞（0243搜尋三檔）。打「~開心」搵同「開心」近義嘅詞；打「!開心」搵反義詞。可加前綴碼，例如「33!開心」。打「~~」搵二字近義複合（如「朋友」「恐懼」）；打「!!」搵二字反義複合（如「生死」「是非」）。語法對稱：~~／33~~／~~你／33~~你，與 !! 系列相同。以上複合詞查詢不適用近反義模式。

About

關於 Canto-0243

ONE·搵·韻 — 離線粵語填詞查找工作台。

簡介

填粵語歌詞時，往往要在同音、押韻、近義之間快速換字，又要對準 0243 與粵拼讀音。Canto-0243 用 0243／02493 數字碼、粵拼、韻母／聲母規則與近義／反義關係，在幾秒內列出符合條件的詞條；套件解壓即用，詞庫與近反義資料存於本地，無需連網。

為何選擇本工具

  • 開源 — 原始碼公開，歡迎檢視、改進與回饋
  • 免費 — 下載即用，無訂閱或按量收費
  • 持續更新 — 維護者持續改進詞庫與功能，並透過 Release 發佈
